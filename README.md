# 📚 Library Management System (Python)

A console-based Library Management System developed in Python that allows users to manage book records efficiently. The application supports adding, editing, deleting, searching, and displaying books while storing data persistently in a text file.

---

## 📖 Features

- Add new book records
- Edit existing book records
- Delete book records
- Search books by ISBN or Author & Title
- Display all books in a formatted table
- Input validation
- Duplicate ISBN detection
- Date validation
- Automatic data saving using text files

---

## 🛠 Technologies Used

- Python
- File Handling
- Functions
- Lists
- Exception Handling
- Datetime Module
- Input Validation

## ▶️ How to Run

1. Clone this repository.

```bash
git clone https://github.com/YOUR_USERNAME/library-management-system-python.git
```

2. Navigate to the project folder.

```bash
cd library-management-system-python
```

3. Run the program.

```bash
python library_management.py
```
